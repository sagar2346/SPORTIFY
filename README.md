# Sportify - About Us Page

This repository contains the standalone frontend code for the "About Us" page of the Sportify application.

## Technologies Used
- React
- Tailwind CSS

## Styling
The styling is managed via Tailwind CSS. The configuration file `tailwind.config.js` is included to ensure the custom color palette (primary and secondary colors) is correctly applied.

## Usage
You can integrate this `About.jsx` component into your React project. Ensure you have Tailwind CSS configured with the provided `tailwind.config.js`.
