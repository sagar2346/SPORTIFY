# Sportify - Online Sport Booking System

A comprehensive MERN stack application designed for seamless sports venue booking and management.

## Features
- **Venue Management**: Browse and book sports venues with real-time availability.
- **AI-Powered Analysis**: Integrated AI for footage analysis and tactical summaries.
- **Secure Payments**: Integrated Stripe payment gateway.
- **Real-time Chat**: Team-based communication via Socket.io.
- **Inventory & KYC**: Built-in inventory management and KYC verification for owners.

## Quick Start

The project is pre-configured for immediate use.

### Prerequisites
- Node.js (v16+)
- MongoDB (Running on localhost:27017)

### Installation & Run

1. **Install Dependencies**
   ```bash
   npm run install-all
   ```

2. **Start the Application**
   ```bash
   npm run dev
   ```
   - Frontend: [http://localhost:5173](http://localhost:5173) (or 3000 depending on port availability)
   - Backend: [http://localhost:5001](http://localhost:5001)

## Project Structure
- `backend/`: Node.js/Express server with Mongoose models and controllers.
- `frontend/`: Vite-powered React application with Tailwind CSS.
